# Transforma-Ações

Painel dos projetos CAPES, FAPEMAT e COP Pantanal, com assistente de gestão em `assistente.html`.

O modo local já oferece lançamentos por projeto/rubrica, saldos calculados, reservas, simulação de compras, ações, documentos originais, backups completos e consultas por comandos. A conversa livre com IA, leitura automática de notas e sincronização entre dispositivos dependem da ativação descrita em `backend/README.md`.

Os orçamentos são referências do painel. Nenhum recebimento ou gasto é inferido deles. O histórico precisa ser preenchido e conferido pelo responsável.

Validação: `npm test`. Abra por um servidor HTTP para carregar os módulos JavaScript.
